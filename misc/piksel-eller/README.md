# Piksel əllər

A dark pixel field with two hands made of white and cobalt marks. Move the pointer between them to make the hands reach inward. Click, tap or use the button to send a blue impulse. Inspired by [Magnus Atom’s Polsia animation process](https://www.pinterest.com/pin/369365606970489071/).

Open [index.html](index.html) in a browser. No build or network connection is required.
