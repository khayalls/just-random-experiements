# Weave Light Studies

- **Light on Weave** — A close-up with blue and violet threads and an optional warm palette.
- **Faded Print** — Lilac and blue halftone ornaments that fade into white behind the heading and at the bottom.
- **Porcelain Relief** — A pale diagonal fold whose woven ornament emerges in soft shadows.

Open [index.html](index.html) in a browser and choose a study below the preview. Move the pointer across the scene or use its action button to try the effect. Use the slider to adjust thread sheen, print density, or relief contrast in the active study.

No build step. The demo runs locally with fallback fonts when Google Fonts is unavailable.
