# Xalça naxışı

An interactive woven background inspired by a carpet reference. Its central medallion, hooked ornaments, rosettes and repeating border are drawn in Canvas. Move the pointer for warm directional light, or click or tap to send a ripple through the weave. The button triggers the same effect from the center. With reduced motion enabled, the ripple becomes a brief stationary glow.

Open [index.html](index.html) in a browser. No build or network connection is required.
