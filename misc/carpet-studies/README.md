# Carpet Studies

- **Dithered Landscape** — A woven landscape with an open area for a hero heading.
- **Thread Map** — A medallion split into three layers of colored knots.
- **Light on Weave** — A close-up of a woven carpet under moving amber light.

Open [index.html](index.html) in a browser and choose a study below the preview. Move the pointer across the scene or use its action button to try the effect.

No build step. The demo runs locally with fallback fonts when Google Fonts is unavailable.
